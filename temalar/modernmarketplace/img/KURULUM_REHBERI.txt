========================================================================
JAAYQUICK.COM — FAVICON.ICO, UYGULAMA İKONLARI VE PWA MANIFEST PAKETİ
========================================================================

Bu arşivde bulunan tüm dosyaları web sitenizin ana kök dizinine (public/ veya
public_html/ klasörüne) olduğu gibi yükleyebilirsiniz.

------------------------------------------------------------------------
PAKET İÇERİĞİNDEKİ DOSYALAR VE GÖREVLERİ
------------------------------------------------------------------------
1. favicon.ico                   -> Çoklu çözünürlüklü (16x16, 32x32, 48x48, 64x64)
                                    gerçek ICO dosyası (Tüm masaüstü tarayıcılar).
2. favicon.svg                   -> Modern tarayıcılar için keskin vektör favicon.
3. favicon-16x16.png             -> Klasik sekme çubuğu ikonu (16x16 px).
4. favicon-32x32.png             -> Retina ekranlı sekme çubuğu ikonu (32x32 px).
5. favicon-48x48.png             -> Google Arama Sonuçları (SERP) site simgesi (48x48 px).
6. favicon-96x96.png             -> Masaüstü kısayol ikonu (96x96 px).
7. apple-touch-icon.png          -> iPhone & iPad "Ana Ekrana Ekle" ikonu (180x180 px).
8. apple-touch-icon-precomposed.png -> Eski iOS sürümleri için yedek ikon (180x180 px).
9. android-chrome-192x192.png    -> Android telefonlarda ana ekran ikonu (192x192 px).
10. android-chrome-512x512.png   -> Android PWA açılış ekranı (Splash Screen) ikonu (512x512 px).
11. maskable-icon-512x512.png    -> Android Adaptive Icon (yuvarlak/damla kesim) uyumlu ikon.
12. safari-pinned-tab.svg        -> macOS Safari sabitlenmiş sekme monokrom vektör ikonu.
13. mstile-150x150.png           -> Windows Başlat Menüsü kutucuk ikonu (150x150 px).
14. og-image-1200x630.png        -> WhatsApp, Facebook ve X'te link paylaşıldığında
                                    çıkan 1200x630 px kurumsal önizleme görseli.
15. site.webmanifest             -> Resmi PWA (Progressive Web App) yapılandırma dosyası.
16. manifest.json                -> Eski araçlar için site.webmanifest yedeği.
17. browserconfig.xml            -> Microsoft Edge / Windows renk ve ikon ayarı.
18. head-meta-tags.html          -> Sitenizin <head> etiketine eklenecek hazır kodlar.
19. nginx-favicon-cache.conf     -> Nginx sunucunuz için önbellek ve MIME-type ayarı.
